# Smart Caption for IINA

1.8.4.0以IINA 1.5.0为适配目标，保持原有配置和功能。详见[更新记录](CHANGELOG.md)。

一个本地 IINA 插件：读取当前启用的文字字幕，将字幕文本发送到 OpenRouter、SiliconFlow 或 OpenAI 兼容服务，用于问答、带时间范围总结，并将回答中的字幕引文变成可点击的跳转链接。回答会流式显示并实时计时，支持 Markdown、复制、追问和编辑后重新发送。

## 安装

1. 从[最新发布页](https://github.com/Ledyce-Lee/IINA-Smart-Caption/releases/latest)下载 `Smart-Caption-for-IINA-1.8.4.0.iinaplgz`，用IINA打开并完成安装；升级时选择替换现有版本。
2. 在 IINA 的“设置 → 插件 → Smart Caption for IINA → Preferences”中填写所需服务商的 API Key；模型按行管理，可用“＋／－”增删。接口地址留空即使用官方默认地址，也可改为兼容接口。
3. 打开视频，在“插件”菜单选择“打开 Smart Caption for IINA”，或按 `Ctrl+Shift+A`。如果没有可用字幕，可点击“生成字幕”，选择必剪、剪映或 Apple SpeechAnalyzer，再选择语言并确认。识别完成后会在视频所在目录生成 `视频名.smart-caption.srt` 并自动载入。
4. 保存未保存的内容，再重启IINA使新版生效。

安装包附有SHA-256校验文件。也可在IINA的插件设置中从GitHub安装，填写 `https://github.com/Ledyce-Lee/IINA-Smart-Caption`。

已有字幕问答只需配置模型服务；Film截图去重需要Swift工具链；媒体合并需要外部FFmpeg与ffprobe；语音识别按所选方式另配VideoCaptioner、Apple SpeechAnalyzer或ASR接口。

## Chat 与 Note

顶部可在 Chat 与 Note 间切换。Chat 中保存的总结会写为 `视频名.summary.md`，普通问答会写为 `视频名.chat.md`。Note 会列出当前视频同一文件夹内、文件名含视频名的全部 Markdown 文件，并可新建 `视频名.summary.md`、`视频名.note.md` 或 `视频名.moment.md`。

Note 阅读状态会保留时间链接的跳转能力；点击“修改”后可使用系统的复制、粘贴、撤销、重做快捷键编辑 Markdown，并同步显示预览。Moment 新建时会立即为当前时间点截图；编辑时点击 Capture 也会在光标位置插入截图和可跳转的时间链接。截图统一保存到对应笔记目录下的 `视频名-图片` 文件夹，不会堆积在视频或笔记根目录。关闭未保存的标签页会显示“保存更改？”确认框。

阅读状态可将当前 Markdown 放入废纸篓；编辑状态下操作区切换为“保存”和“取消”。取消未修改内容会直接退出，取消已有修改会询问是否保存。每个标签页会独立记住编辑状态，来回切换不会退出正在编辑的文件。编辑区与 Markdown 预览区之间的分隔线可左右拖动。文件选择框始终显示选择提示；标签页对长文件名进行中间省略，只保留`.note`、`.summary`等类型后缀，不显示末尾的`.md`。

设置页的“Note 文件位置”可控制读取范围：视频所在文件夹始终启用，视频默认附件文件夹默认启用，其他路径支持按相对视频位置或绝对路径添加。新建 Markdown 与附件保存位置只能从当前读取范围中选择；若路径被取消或删除，保存位置会自动回到视频所在文件夹。

## 外观与模型

模型行右侧的上、下按钮可调整模型显示顺序。配色中的色块与十六进制值会同步更新；点击“保存当前主题”后可为整套配色命名并确认保存，已保存主题可从下拉框应用或删除。主题同时写入主偏好、独立备份偏好和插件数据目录，插件升级后会自动恢复。

## 双语字幕

加载可读取字幕后，点击“生成翻译”。可选择谷歌翻译、DeepL 或已有的 OpenAI 兼容模型，并生成独立字幕或双语字幕。生成文件会保存到视频同目录并自动载入。

## 字幕兼容与取消

问答和总结支持 SRT、VTT、ASS/SSA、MicroDVD SUB、SubViewer、SAMI、TTML 与 LRC 等常见文字字幕格式。VTT 中的样式、逐词时间标签和网页实体会在发送前清理，连续短片段会合为保留时间范围的语义段，避免模型长时间只返回推理内容。模型生成期间，可在回答气泡右下角点击“取消”立即结束本次等待并恢复提问。

## 使用边界

字幕问答会将所选字幕文本和问题发送至你配置的模型服务；附图问答会发送主动选择的图片。云端语音识别会发送待识别音频片段，本地识别的处理方式取决于所选工具。图片字幕、没有文字层的内嵌字幕可能无法读取；此时请加载外置文字字幕或生成字幕。请按功能选择可信任的服务和所需凭据。

模型输出直接按 Markdown 显示；界面只展示“思考中”“生成中”等进度，不展示模型内部推理文本。插件要求模型将每项视频结论标为 `([mm:ss]-[mm:ss])` 或 `([hh:mm:ss]-[hh:mm:ss])`，并把该时间范围渲染为跳转链接。超长字幕会按设置的字符上限截取：问答优先传递与问题相关的字幕片段，总结则均匀覆盖全片。API URL 留空时使用各服务商的官方 Chat Completions URL。
